# ✨ Modern Yellow Vibrant Design System

A bold, energetic, and premium UI style focused on vibrant yellow tones, soft shadows, glassmorphism, and modern layouts.

---

# 🎨 Colors

| Name | Hex |
|---|---|
| Primary Yellow | `#FFD60A` |
| Bright Gold | `#FFB703` |
| Soft Yellow | `#FFE45E` |
| Background | `#FFFBEA` |
| Surface | `rgba(255,255,255,0.75)` |
| Text Primary | `#1A1A1A` |
| Text Secondary | `#6B7280` |

---

# 🖥️ Overall Style

- Clean modern SaaS aesthetic
- Vibrant yellow accents
- Large rounded corners
- Soft blurred glass effects
- Smooth animations
- Spacious layouts
- Minimal but playful
- Premium startup feel

---

# 🔤 Typography

## Headings
- Font: `Poppins`
- Weight: `700`
- Letter spacing: `-0.03em`

## Body
- Font: `Inter`
- Weight: `400-500`
- Comfortable spacing
- High readability

---

# 📦 Components

## Buttons

### Primary Button

```css
background: linear-gradient(135deg, #FFD60A, #FFB703);
color: #1A1A1A;
padding: 14px 24px;
border-radius: 18px;
font-weight: 600;
border: none;
cursor: pointer;
transition: 0.25s ease;
box-shadow: 0 10px 30px rgba(255, 214, 10, 0.35);
```

### Hover Effect

```css
transform: translateY(-2px) scale(1.02);
box-shadow: 0 14px 40px rgba(255, 214, 10, 0.45);
```

---

# 🌈 Gradients

## Main Gradient

```css
background: linear-gradient(
  135deg,
  #FFD60A 0%,
  #FFB703 100%
);
```

## Background Glow

```css
background: radial-gradient(
  circle at top left,
  rgba(255,214,10,0.35),
  transparent 50%
);
```

---

# 📱 Layout Rules

- Use lots of whitespace
- Prefer centered layouts
- Maximum width: `1200px`
- Mobile-first responsive design
- Use CSS Grid whenever possible
- Avoid clutter
- Keep sections visually separated

---

# ✨ Effects

## Glassmorphism

```css
backdrop-filter: blur(14px);
background: rgba(255,255,255,0.7);
```

## Glow

```css
box-shadow: 0 0 60px rgba(255, 214, 10, 0.25);
```

## Smooth Animation

```css
transition: all 0.25s ease;
```

# 💡 Extra Design Notes

- Use floating blurred yellow blobs in backgrounds
- Add subtle motion on hover
- Prefer soft shadows over hard borders
- Use gradients sparingly for emphasis
- Keep typography large and readable
- Avoid dark heavy interfaces
- Use rounded corners everywhere
